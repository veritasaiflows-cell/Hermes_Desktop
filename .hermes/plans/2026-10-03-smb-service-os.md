## Minimum viable service OS

Reuse this chain: **AI Workflow Diagnostic (conversation → task/process analysis → baseline → integration feasibility → business case) → scoped pilot → approved access → test → deliver → observe → improve/offboard**.

1. Workspace control plane owns workflow state, lane leases, dispatch and stop lines. Each engagement receives an ID and explicit owner; no model can promote itself.
2. Every client gets its own profile, authorized contacts, permissions, source manifest, SQLite store, evidence, logs and retention agreement. Never put client records in the global business knowledge graph or a shared vector index. [SUPERSEDED/QUALIFIED: Target design; synthetic six-field contract unchanged. See architecture decisions.]
3. Existing `platform/` contracts remain the common-data foundation. Do not add `platform/__init__.py` or shadow Python's stdlib `platform` module.
4. Capability catalog: process audit; CSV/reporting; intake routing; invoice/follow-up drafts; structured document extraction. The last three are offers to scope, not implemented modules. Prefer the client's existing systems; adapters start read-only, then draft, then separately approved write.
5. Rules/calculations/reconciliation use deterministic code. AI is reserved for ambiguous extraction/classification/drafting with schemas, evidence, abstention and human review. No AI for arithmetic, granting access, silently changing money or claiming success.
6. Execution design records request/batch IDs, source hashes, idempotency keys, retries, exceptions, exact approval scope/expiry, reconciliation and rollback. Approval is bound to the payload; edits invalidate it. These remain specs until tested.
7. Tests require empty/malformed/conflicting/replayed inputs, same-tenant access and cross-tenant denial. Local directory/API isolation is **not** hostile-process or production multi-tenant security; use separate identities/environments before promising stronger isolation.
8. Measure staff time, rework, response delay and exception rate. Time released is capacity, not cash revenue; cost savings require an actual cost change.
